GEO LOCATIONS
Geo data is extracted from Github project repository : Countries States Cities Database.
Select the countries and we will download, extract and insert selected country's cities, states, postcodes into the database.
NOTE: This tool will overwrite any local changes you have made to Geo database!

TIME ZONES
Time zone data is extracted from the Wikipedia page : List of tz database time zones.
Extractor will extracts data from the table shown on the Wikipedia page and inserts the information into time zone database.
