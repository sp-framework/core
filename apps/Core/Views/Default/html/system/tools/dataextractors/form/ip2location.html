IP2LOCATION IP DATABASE
IP2Location data BIN file is retrieved from IP2Location Website
You can download the free (lite) version of the file or the paid version.

IP2Location also provides an online API REST service via IP2Location IO Website

IP2Location is used by IpTables middleware to allow/block region (Country & City) based access to a particular app.
NOTE: This tool will download the BIN file. To use ip2location.io api, configure the API key in the middleware settings.
